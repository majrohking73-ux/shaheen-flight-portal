SHAHEEN UMRAH TRAVEL - FACEBOOK FLIGHT BOOKING PORTAL

This is a mobile-friendly website that can be linked from your Facebook Page.
It includes:
- One Way / Return / Multi City selection
- From / To
- Departure / Return date
- Class and passenger count
- Customer name, phone, email, city and comments
- WhatsApp booking request

IMPORTANT:
The current portal is a booking-request system, not a live airline inventory/search engine.
To show real-time fares, seats and confirmed tickets, an airline/GDS/API connection is required.

WhatsApp number is set in index.html in the line:
const WA_NUMBER = "966599002965";
